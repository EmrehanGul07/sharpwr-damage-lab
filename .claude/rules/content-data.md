# Content and data provenance rules

- Every number is `{"value": "<decimal text>", "status": "<status>", "source": "<where>"}`.
  Status vocabulary and meaning: `docs/moba/02-data-migration.md`.
- Unknown values are `status: "unresolved"`, `value: null`. Never fill them from memory, PC
  LoL, other champions, or "reasonable" guesses. Add the gap to the champion's
  `unsupported_mechanics` and to the milestone report.
- Reference (Riot) data: only in `game/content/reference-riot/`, `ip: "riot-reference"`,
  `shippable: false`. Generated by `tools/data_import` — do not hand-edit.
- Original content: `ip: "original"`; statuses `original_design`, `original_placeholder`,
  `unresolved` only. `source` names the design doc/ticket.
- Fixtures are generated by `tools/parity/*.py` from the Python engine; never edit them by hand.
  Changing expected values requires a fixture version bump and an explanation.
- Run `python -I tools/content/validate_content.py` and the exporters' `--check` before finishing.
- Read the Damage Lab freely; never write to it.
